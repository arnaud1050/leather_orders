Synchronisation

These apply to every mailbox this company has connected. "How far back to read" only affects a mailbox's first sync — after that each run picks up where the last one finished.

With "keep mail from unknown senders" off, the app stores only conversations it can tie to a client already on file and discards the rest. With it on, unmatched mail collects in Leads, where it can be turned into a client.

Security

Access tokens are encrypted before they're written to the database, and the key that decrypts them is held in the environment rather than alongside the data. Disconnecting revokes the grant at Google.

{% if using_derived_key %}

Tokens are being encrypted with a key derived from SECRET_KEY, the development fallback. Set COMMS_ENCRYPTION_KEY before connecting a real mailbox — otherwise changing SECRET_KEY makes every stored token unreadable and each account has to be reconnected.

{% endif %}
