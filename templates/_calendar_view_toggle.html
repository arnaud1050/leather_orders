{# Month/week toggle for the calendar header — two icon buttons switching between the month grid and the week grid. Both show the same synced-events-only calendar (CAL-1); this only changes how much of it is on screen at once. Shared by calendar.html and calendar_week.html so the two don't drift, same reasoning as _settings_nav.html. Callers set calendar_view_mode ("month" or "week") plus month_link_year/ month_link_month and week_link_year/week_link_month/week_link_day — the target of each icon, which is "itself" from the active view and "a reasonable date inside what's currently showing" from the other. #}
