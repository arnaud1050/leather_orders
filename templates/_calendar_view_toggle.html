{# Month/week toggle for the calendar header — two icon buttons switching between the month grid and the week grid. Both show the same synced-events-only calendar (CAL-1); this only changes how much of it is on screen at once. Shared by calendar.html and calendar_week.html so the two don't drift, same reasoning as _settings_nav.html. Each icon always lands on the *current* month or week, whichever view you're leaving from and however far you'd navigated — the prev/next arrows are for wandering, this is for coming home. Callers set calendar_view_mode ("month" or "week") to mark which icon is active. #}
